The Domain Name Information Groper (**dig**)
## What is this command?

It's a tool used for troubleshooting problems with the Domain Name System (**DNS**).

> What is **DNS**?
> It's like a phonebook for the internet, helping computers find each other's addresses. The command helps you understand how DNS works and find issues with it.

## How does it work?

When using the `dig` command, it sends requests to a DNS Server to find the address of a specific website or domain name. The DNS Server then responds with the answer, in which the `dig` command then displays.

### Common uses

- **Troubleshooting DNS issues**: The `dig` command can help you  understand how DNS is working and find issues with it.
- **Performing DNS lookups**: It can help find the address of a specific website or domain name.
- **Testing DNS Servers**: To test how a DNS server is responding to queries.
