# What is an Access Control List

It contains rules that grant or deny access to certain digital environments.
### There are two types:
- **Filesystems ACLs** -> filter access to files and/or directories. They tell operating systems which users can access the system, and what privileges the users are allowed.
- **Networking ACLs** -> filter access to the network. Networking ACLs tell the routers and switches which type of traffic can access the network, and which activity is allowed.

> [!NOTE]
> Originally, ACLs were the only way to achieve firewall protection. Today, there are many types and alternatives to ACLs. But, organizations continue to user ACLs in conjunction with technologies like virtual private networks (VPNs) that specify which traffic should be encrypted and trasnferred through a VPN tunnel.

## Reasons to use an ACL

- Traffic flow control
- Restricted network traffic for better performance
- A level of security for network access specifying which areas of the server/network/service can be accessed by a user and which cannot.
- Granular monitoring of the traffic exiting and entering the system.
