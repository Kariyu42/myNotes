
## What are security frameworks?

They are guidelines for building plans to help mitigate risk and threats to data and privacy.

### Purpose of security frameworks

- Protect PII
- Securing financial information
- Identifyinng security weaknesses
- Managinz organizational risks
- Aligning security with business goals

# Components of Security frameworks

![[Components.png]]

1. Identifying and documenting security goals
2. Settings guidelines to achieve security goals
3. Implementing strong security processes
4. Monitoring and communicating results

### Security controls: What is it?

Safeguards designed to reduce specific security risks.

### CIA Triad: What is it?

A foundational model that helps inform how organizations consider risk when setting up systems and security policies.
