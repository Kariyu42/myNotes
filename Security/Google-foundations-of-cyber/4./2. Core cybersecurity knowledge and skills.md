
### **Summary of Using Tools to Protect Business Operations**

#### **Programming for Security Analysts**

- **Python**: Used for **automation**, reducing manual effort and human error.
- **SQL**: Used to **interact with databases**, manage large datasets, and retrieve information efficiently.

#### **Operating Systems**

- **Linux, macOS, and Windows** are key operating systems for security analysts.
- **Linux** is **open-source**, allowing modifications and contributions.
- Analysts use the **command-line interface (CLI)** for system operations and security tasks.

#### **Key Cybersecurity Tools & Concepts**

- **Web Vulnerabilities**: Flaws in web applications that can be exploited by attackers. Analysts use the **OWASP Top 10** to stay updated on critical risks.
- **Antivirus Software**: Detects, prevents, and removes malware and viruses.
- **Intrusion Detection System (IDS)**: Monitors network activity, detects **theft and unauthorized access**, and alerts on possible intrusions.
- **Encryption**: Converts plaintext into **ciphertext** to secure data and ensure **confidentiality**.
- **Penetration Testing (Pen Testing)**: Simulated cyberattacks to identify system vulnerabilities.

#### **Key Takeaways**

- **Security analysts use various tools** to protect systems and data.
- **Understanding multiple tools** increases job value, as organizations use different security solutions.
- **Programming, OS knowledge, and security tools** are essential for protecting business operations efficiently.

### **Summary of Creating a Cybersecurity Portfolio**

#### **What is a Portfolio & Why is it Important?**

- A **portfolio** showcases a cybersecurity professional’s **skills, education, and experience** beyond a traditional resume.
- It **demonstrates passion and competence** to potential employers.
- A **resume** is a **brief summary**, whereas a **portfolio** provides **detailed projects and work samples**.

#### **Portfolio Hosting Options**

1. **Documents Folder**
    
    - **Local storage** on a computer for organizing professional documents.
    - Can include subfolders like **Resume, Education, Portfolio Documents, Cybersecurity Tools, and Programming**.
2. **Google Drive / Dropbox**
    
    - **Cloud storage** with easy file-sharing and automatic updates.
    - Helps keep **portfolio documents well-organized** for job applications.
3. **Google Sites (or similar website builders)**
    
    - Provides **customizable layouts, responsive webpages, and web publishing**.
    - Employers can **easily access portfolio items via a shared URL**.
4. **Git Repository (GitHub, GitLab, Bitbucket)**
    
    - Stores **documents, labs, and screenshots** in a structured format.
    - Uses **Markdown** for customization and documentation.

#### **Portfolio Projects to Include**

- **Professional statement**
- **Security audit**
- **Network structure and security analysis**
- **Linux commands for file permissions**
- **SQL query filtering**
- **Vulnerability identification**
- **Incident handling documentation**
- **Security-related text file parsing**
- **Resume creation/revision**

#### **Key Takeaways**

- **A well-organized portfolio enhances job prospects** in cybersecurity.
- **Choose the best hosting option** based on your needs.
- **Keep the portfolio private** until it is fully polished.
- **Be proactive in building a portfolio** throughout the learning process to **stand out to employers**.
